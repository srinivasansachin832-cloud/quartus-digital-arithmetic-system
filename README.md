# Quartus Digital Arithmetic System

A digital logic design project implemented in Quartus featuring an 8-bit adder, accumulator, down counter, and multiplier.

## Overview
This project combines several core digital design components into a larger arithmetic and sequential logic system. The work was developed and verified in Quartus using block diagrams and waveform simulation.

## Included Components
- 8-bit adder
- 8-bit accumulator
- Adder/accumulator integration
- TFF-based binary down counter
- Synchronous-load counter
- Multiplier design

## Engineering Concepts Used
- Combinational logic
- Sequential logic
- Flip-flops
- Counter design
- Arithmetic circuit design
- State transition logic
- K-map minimization
- Digital waveform simulation
